# Set up the ChatGPT Project

## Create the Project

1. In ChatGPT, select **New project** in the sidebar.
2. Name it **VARDA | Venture Lab**. The Varda name remains provisional.
3. Open the Project menu (`•••`) → **Project settings**.
4. Paste the full contents of `PROJECT_INSTRUCTIONS.md` into Project instructions.
5. Add the following compact sources:
   - `VARDA_PROJECT_CONTEXT.md`
   - `../docs/00_foundation/first_principles_reset.md`
   - `../docs/01_market/opportunity_hypotheses.md`
   - `../docs/01_market/customer_discovery_plan.md`

This is designed to fit the five-file Project source allowance on the Free plan, leaving one spare slot. Upload the original source files only if you have additional file capacity or replace a compact source after the first synthesis. The full originals are preserved in the Codex repository.

## Organise chats inside the Project

Create separate chats for distinct workstreams:

- `00 | Founder OS and operating decisions`
- `01 | First-principles reset`
- `02 | Market and technology intelligence`
- `03 | Customer discovery and outreach`
- `04 | Opportunity selection`
- `05 | Product and technical definition`
- `06 | December pilot and proof`

Start from the Project for each new chat so its instructions and sources are applied. Save important ChatGPT responses back into Project sources when they become approved working artefacts.

## Source limit note

OpenAI's current Projects help page states that Free users can upload up to five files per project; upload allowance varies by plan. Check the current UI/help page if the limit changes.
