## Rules

- Add an assumption only if it affects a decision.
- Give each assumption an owner and a next test when work begins.
- Update status to Supported, Weakened, Rejected or Still unknown; include the evidence reference.
- Do not convert “a customer liked the idea” into “demand validated.”
